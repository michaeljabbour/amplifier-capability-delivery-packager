# Reuse decisions

| Source | Decision | Boundary |
|---|---|---|
| Existing Python standard library | Actual runtime reuse | ZIP, hashes and descriptor-relative file operations; no copied implementation. |
| Owned optional coaching guide | Included MIT documentation | Versioned local text; no mandatory service or installation. |
| Owned shared capability installer | Optional external discovery route | One shared implementation; no per-harness installer copies. Native tool installation is explicit. |
| Existing campaign evidence packager | Inspected, not reused | Campaign-specific behavior and paths do not become this public API. |
| Public tools and papers | Research only | Exact relationships and limits in RELATED.md; no new adoption. |

No measured quality, cost, learning, market adoption or partnership claim follows from these decisions.
